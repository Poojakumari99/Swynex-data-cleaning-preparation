# Swynex-data-cleaning-preparation
This project is completed as a part of my Data analyst Internship at Swynex Technologies.
Objective:- To Identify and resolve common data quality issues in a real world dataset and prepare the data for further analysis. The dataset is cleaned and transformed using Microsoft Excel.
The following issues were identified during the initial inspection:-
1. Missing Values
2. unknown and error entries
3. incorrect data types
4. missing values in terms of numeric and categorical fields
5. transaction date
6. duplicate records check.
